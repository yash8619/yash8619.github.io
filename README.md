## Run locally
Open `index.html` in a browser. No build tools or installation are required.

## Publish on GitHub Pages
1. Create a public repository named exactly `YOUR-GITHUB-USERNAME.github.io`.
2. Upload `index.html`, `style.css`, `script.js`, and this `README.md` to the repository root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. Wait for deployment, then visit `https://YOUR-GITHUB-USERNAME.github.io`.

GitHub Pages serves static files; this site itself does not run Python or host a live ML model. Deploy Python model demos separately (for example, using a suitable Streamlit hosting option) and add their URLs to the project cards when ready.
